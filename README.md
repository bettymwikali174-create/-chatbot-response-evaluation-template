# Chatbot Response Evaluation Template

A simple, reusable template for comparing two chatbot responses to the same prompt and writing a clear final assessment.

## What this project is

When two chatbots answer the same question, it is not enough to say "A is better." This template shows a consistent way to score each response, explain the scores and give a final verdict that someone else can follow and check.

## What is in this repository

- `rubric.md` explains how to score a response from 1 to 5 on accuracy, relevance, completeness and clarity.
- `sample-evaluations.md` has three fictional prompts, two responses for each, and a full worked evaluation.

## How to use it

1. Read the prompt and both responses fully before scoring.
2. Score each response on the four criteria using `rubric.md`.
3. Write one or two sentences explaining each score. Point to the exact part of the response that caused it.
4. Name the better response and write a short final assessment.
5. Re-read the guidelines and check that your scores are consistent with earlier evaluations.

## Important note

All prompts and responses in this repository are fictional and written by me for demonstration. None of them come from any client, platform or real project.
